
# ⚔️ Nova Strike

**A wave-survival action game built with React and Vite.**

Nova Strike is a browser-based action survival game where players fight enemy waves, use combat abilities, and try to survive increasingly challenging encounters.

## 🎮 Features

- ⚔️ Action-oriented combat gameplay
- 👾 Enemy wave survival
- 🛡️ Player health and combat mechanics
- ✨ Special abilities and cooldowns
- 🎯 Challenging survival experience
- 🎨 Interactive game visuals and animations
- ⚡ Fast development and performance with Vite
- 📱 Responsive UI improvements *(if implemented)*

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Language:** JavaScript
- **Styling:** CSS
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- Git *(optional, for cloning)*

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/nova-strike.git
   ```

2. Navigate to the project folder:

   ```bash
   cd nova-strike
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually:

   ```text
   http://localhost:5173
   ```
